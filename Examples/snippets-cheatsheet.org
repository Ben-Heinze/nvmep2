* How it works

- *Math snippets are auto-expanding* (LuaSnip autosnippets): they fire the
  instant you finish typing the trigger. No <Tab> or menu needed.
- *They only fire inside a math zone* -- between ~$ ... $~, ~$$ ... $$~,
  ~\( ... \)~, ~\[ ... \]~, or a math environment (~\begin{align}~, ~cases~,
  ~bmatrix~ ...). In ordinary prose the same words are left untouched, so
  writing "the sum is large" will not turn into "\sum".
- *Enter math fast* with ~mk~ (inline ~$ $~) or ~dk~ (display ~\[ \]~). The org
  snippets ~mm~ / ~dm~ do the same via the completion menu.
- *Auto-pairs*: typing ~(~ ~[~ ~{~ or ~$~ inserts the closing partner; type the
  closing char to skip over it instead of adding a new one.
- Everything works in ~.org~ files (and ~.tex~) anywhere on disk.

* Entering & moving around

| Key            | Action                                                             |
|----------------+--------------------------------------------------------------------|
| ~mk~           | insert inline math ~$ $~ (cursor lands between)                     |
| ~dk~           | insert display math ~\[ \]~ (cursor lands inside)                   |
| <Tab>          | expand snippet / jump to next placeholder / jump out of braces / accept menu |
| <S-Tab>        | jump to the previous placeholder                                   |
| <CR> (Enter)   | confirm the highlighted completion item (otherwise a normal newline) |
| <C-n> / <C-p>  | select next/prev menu item, or jump forward/back in a snippet      |
| <C-y>          | always confirm the current completion                              |
| <M-e>          | auto-pairs "fast wrap": wrap the next word in the last-typed pair  |

* TikZ graphs (nodes, values, weighted edges)

Regular snippets (type the trigger then <Tab> / <C-n>). Nodes stack a *name* and
a *value* in one box; layout is automatic, so you only describe connections.
These export to PDF via LuaLaTeX -- <Space>oe renders them like any other note.

| Trigger  | Inserts                                                       |
|----------+---------------------------------------------------------------|
| ~graph~  | full ~tikzpicture~ + ~\graph{}~ scaffold (first field: layout) |
| ~gnode~  | one node, name/value stacked: =id [as={name \\ value}]=       |
| ~gedge~  | edge =a <dir> b;= (choose -- / -> / <-> with <C-n>)           |
| ~gwedge~ | weighted edge =a <dir>["w"] b;=                               |

The =graph= layout field is a choice node: <C-n> cycles =spring layout= (organic),
=layered layout= (top-down / DAGs), =tree layout=. Add ~gnode~ / ~gedge~ / ~gwedge~
lines inside the =\graph{ ... }= block to grow the graph.

Worked example -- a 3-node weighted graph:

#+begin_src latex
  \begin{tikzpicture}[
    >={Stealth[]},
    every node/.style={draw, circle, align=center, inner sep=4pt},
  ]
    \graph[spring layout, node distance=20mm]{
      a [as={Start \\ 0}] ->["3"] b [as={B \\ 3}];
      b ->["5"] c [as={Goal \\ 8}];
      a ->["9"] c;
    };
  \end{tikzpicture}
#+end_src

...which renders (raw =\begin{tikzpicture}= at column 0 exports verbatim to PDF):

\begin{center}
\begin{tikzpicture}[
  >={Stealth[]},
  every node/.style={draw, circle, align=center, inner sep=4pt},
]
  \graph[spring layout, node distance=20mm]{
    a [as={Start \\ 0}] ->["3"] b [as={B \\ 3}];
    b ->["5"] c [as={Goal \\ 8}];
    a ->["9"] c;
  };
\end{tikzpicture}
\end{center}

* Fuzzy LaTeX-command finder

For any command not covered by a snippet, type a backslash and start the name
inside an org/tex/markdown buffer -- a fuzzy menu (cmp-latex-symbols) appears:

: \alp     -> menu: \alpha  \aleph  ...   (press <CR> to insert)

It inserts the ~\command~ form, so it renders correctly in LaTeX/Org.
